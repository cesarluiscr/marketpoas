# MarketPoás 🌋

Marketplace del cantón de Poás, Alajuela, Costa Rica.

## Características

- 📱 PWA instalable en Android
- 🗺️ Mapa interactivo del cantón
- 💬 Chat entre compradores y vendedores
- 🏛️ Tablón de la municipalidad
- 🎉 Eventos del cantón
- 🏪 Comercios locales
- ⭐ Reseñas y calificaciones
- 🔐 Verificación de identidad (KYC)
- 🌙 Modo oscuro
- 👤 Panel de administrador

## Tech Stack
- Next.js 16 + TypeScript
- Prisma ORM (SQLite)
- Tailwind CSS 4 + shadcn/ui
- NextAuth.js
- Socket.io (chat en tiempo real)
- Leaflet (mapa)
